# 한국어 규율

ASD-STE100은 영어 전용 규격이다. 이 파일의 규칙은 국립국어원의 공공언어 지침, 업계 테크니컬 라이팅 가이드, 기계번역 전처리 연구에서 가져왔다. 숫자 한도 중 공식 근거가 있는 것은 따로 표시했다.

목차: 1. 문장 · 2. 종결 어미 · 3. 용어 · 4. 경고와 주의 · 5. 오류 메시지 · 6. 어절 세기 · 7. 고쳐 쓰기 예시

## 1. 문장

- 한 문장에는 정보를 한두 가지만 담는다. 국립국어원 지침의 기준이다. 절차 문장에는 지시를 하나만 쓴다.
- 절차 문장은 20어절 이하, 설명 문장은 25어절 이하, 설명 문단은 6문장 이하로 쓴다. 이 한도는 이 스킬의 기준이다. 공식 한국어 기준에는 어절 한도가 없고, 국립국어원 보도자료 지침은 "되도록 3줄 이하"를 권한다.
- 조사와 어미를 줄이지 않는다. `계획을 수립, 시행`은 `계획을 수립하여 시행`으로 쓴다.
- 같은 종류끼리 잇는다. `평화 수호와 인권을 보장하는 것`은 `평화를 수호하고 인권을 보장하는 것`으로 쓴다.
- 꾸미는 말은 꾸밈을 받는 말 가까이에 둔다.
- 사물이나 추상 개념을 행위자로 쓰지 않는다. `이 라이브러리는 초기화를 수행해요`는 `이 명령어를 실행하면 데이터베이스를 초기화할 수 있어요`로 쓴다.
- 조건이 셋 이상이면 번호 목록으로 쓴다.

## 2. 종결 어미

| 글의 종류 | 지시 | 설명 | 의무 |
|---|---|---|---|
| 절차, 개발자 문서 | -세요, -지 마세요 | -ㅂ니다 | -어야 합니다 |
| 보고서, 보도자료 | 쓰지 않음 | -ㄴ다, -다 | -어야 한다 |

- 한 문서에서는 한 체계만 쓴다.
- `-십시오`는 약관과 법률 문서에 남긴다. 일반 절차에는 `-세요`를 쓴다.
- 명사형 지시(`복용할 것`)는 `복용하세요`로 쓴다.
- 조건의 연결 어미는 뜻에 맞춰 고른다. 상황에는 `-ㄹ 때는`, 상태에는 `-ㄴ 경우`, 사건에는 `-면`, 목적에는 `-려면`을 쓴다.

## 3. 용어

- 한 개념에는 한 용어만 쓴다. `추가`, `첨부`, `넣다`를 섞지 말고 하나로 정한다.
- 약어는 처음에 풀어 쓴다. `SSR(Server-Side Rendering)`, `인공지능(AI)`
- 화면의 버튼 이름과 메뉴 이름은 화면에 보이는 글자와 똑같이 쓴다.
- 쉬운 우리말이 있으면 그 말을 쓴다. `컨펌`은 `확인`, `다운받아`는 `내려받아`, `내구연한`은 `사용 가능 햇수`로 쓴다.
- 외래어 표기는 회사 규정을 따른다. 규정이 없으면 국립국어원 표기를 따른다.
- 중복 표현을 쓰지 않는다. `과반수 이상`은 `과반수`, `제출 유무 여부`는 `제출 여부`로 쓴다.

## 4. 경고와 주의

- 경고: 사람이 다치거나 죽을 수 있는 위험. 주의: 장비, 제품, 데이터가 손상될 수 있는 위험. 이 구분은 STE 정의를 따른다. 제품 안전 규정이 다른 등급 체계를 쓰면 그 규정을 따른다.
- 경고는 해당 동작 바로 앞에 쓴다.
- 신호어 다음에 명령이나 조건을 쓰고, 그 다음에 위험을 쓴다.
- 참고에는 정보만 쓴다. 참고에 위험이나 지시가 있으면 경고나 주의로 바꾼다.

```
경고: 패널을 열기 전에 배터리를 분리하세요. 단자에 높은 전압이 있어 감전될 수 있습니다.
```

## 5. 오류 메시지

무엇이 실패했는지, 프로그램이 무엇을 했는지, 사용자가 무엇을 해야 하는지 쓴다.

- `Cannot ...`은 `~할 수 없습니다`, `Failed to ...`는 `~하지 못했습니다`로 쓴다.
- `새로 고침 수행에 실패했습니다`는 `새로 고치지 못했습니다`로 쓴다.
- `계속하기를 원하십니까?`는 `계속하시겠습니까?`로 쓴다.
- 사용자가 고칠 수 있는 오류인지 알려 준다.

```
config.yaml을 읽을 수 없습니다. 파일이 없어서 기본값을 사용합니다. 다른 파일을 쓰려면 CONFIG_PATH를 설정하세요.
```

## 6. 어절 세기

띄어쓰기 단위 하나가 1어절이다. 다음은 각각 1어절로 센다: 괄호 안의 글, 숫자와 단위(`25 Nm`), 약어, 코드, 따옴표 안의 글, URL. 단계 번호는 세지 않는다. `check.py`는 이 방식으로 센다.

## 7. 고쳐 쓰기 예시

절차

> 전: 사용자는 설정 파일을 변경한 후 저장하고, 변경 사항이 적용되었는지 확인한 다음, 필요하면 서버를 다시 시작해야 합니다.
>
> 후:
> 1. 설정 파일을 변경하세요.
> 2. 파일을 저장하세요.
> 3. 변경 사항이 적용되었는지 확인하세요.
> 4. 적용되지 않았으면 서버를 다시 시작하세요.

> 전: 애플리케이션이 실행되기 전에 설정이 완료되어야 합니다.
>
> 후: 애플리케이션을 실행하기 전에 설정을 완료하세요.

설명

> 전: API 키를 이용한 사용자 인증 처리가 완료된 후, 데이터베이스 접속 설정 진행이 가능합니다.
>
> 후: API 키로 사용자를 인증한 후, 데이터베이스 접속을 설정할 수 있습니다.

명사 나열

> 전: 악취발생우려및집중호우시침출수지하토양오염우려
>
> 후: 악취가 발생할 수 있습니다. 집중 호우 때는 침출수가 지하 토양을 오염시킬 수 있습니다.

첫 번째 절차 예시는 한 문장에 있던 동작 넷을 단계 넷으로 나눴다. 그리고 "필요하면"을 "적용되지 않았으면"으로 바꿨다. 원문이 조건을 밝히지 않아서 고친 사람이 조건을 골랐다. 이런 선택은 보고서에 쓴다.
